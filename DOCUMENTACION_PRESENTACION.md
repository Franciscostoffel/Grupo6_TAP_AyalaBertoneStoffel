# Inversion Inteligente - guia para una presentacion oral

## 1. Que problema resuelve

La aplicacion ayuda a comparar opciones de inversion sin tener que revisar
muchas paginas distintas. El usuario indica cuanto dinero tiene, durante cuanto
tiempo quiere invertir y que nivel de riesgo acepta.

La app muestra plazos fijos, fondos comunes de inversion, billeteras virtuales
y bonos. Los resultados son informativos: no son una recomendacion financiera.

## 2. Como se usa

1. Se entra a la pagina.
2. Se escribe el capital disponible.
3. Se elige un plazo en dias.
4. Se selecciona un perfil de riesgo: bajo, moderado o alto.
5. Se presiona **Analizar inversiones**.
6. La app muestra las entidades y ordena las opciones por rendimiento.
7. Se puede abrir cada banco o billetera para ver sus productos.

La simulacion y la consulta de bonos se pueden usar sin iniciar sesion.
El inicio de sesion se pide solamente para guardar informacion personal.

## 3. Que muestra cada resultado

Cada tarjeta puede mostrar:

- el nombre del banco, billetera o fondo;
- el tipo de inversion;
- el nivel de riesgo;
- la tasa nominal anual, cuando existe;
- la ganancia estimada;
- el monto final estimado;
- la liquidez, es decir, cuando se puede retirar el dinero;
- si el producto esta disponible desde la aplicacion de la entidad.

Los fondos no garantizan una ganancia. Su rendimiento se calcula usando datos
publicados y puede cambiar.

## 4. Plazos fijos

Para los bancos, la app busca la tasa publicada para el plazo elegido. Si no
hay una tasa exacta, usa la tasa publicada mas cercana que corresponda.

La ganancia se calcula para el capital y la cantidad de dias elegidos.

## 5. Fondos comunes de inversion

Los fondos se agrupan segun la entidad que los administra. La aplicacion los
clasifica por riesgo y calcula un rendimiento estimado para el plazo elegido.

Una billetera como Mercado Pago o Uala aparece porque el dinero de su cuenta
rinde mediante fondos comunes de inversion.

## 6. Bonos

La seccion de bonos muestra letras y bonos del Tesoro que cotizan en el
mercado. Para los bonos de tasa fija, la app estima la ganancia hasta el
vencimiento usando el capital ingresado.

Los bonos CER muestran principalmente su rendimiento real, porque la ganancia
final depende de la inflacion futura.

## 7. Favoritos y preferencias

Con una cuenta se puede:

- guardar una inversion favorita;
- marcar bancos o billeteras favoritas;
- elegir un banco principal;
- filtrar la lista para ver solo favoritos;
- consultar todo desde **Mis favoritos**.

El favorito guarda una copia de los valores que tenia la inversion cuando se
guardo. La app compara esa copia con los datos actuales.

## 8. Comparacion de cambios

La app conserva la inversion original durante todo el tiempo que permanece en
favoritos. Cuando se abre la pantalla de favoritos, compara esa copia con los
datos actuales.

La pantalla muestra:

- **Al guardar**: los valores originales;
- **Con datos actuales**: los valores vigentes;
- **Hay datos nuevos**: si algun valor cambio.

No se guarda un historial completo. Esto mantiene la base de datos pequena y
alcanza para saber como cambio la inversion desde el momento en que se guardo.
Al eliminar el favorito, tambien se elimina la copia original. Si se vuelve a
guardar, comienza una nueva comparacion.

## 9. Actualizacion de datos

Las fuentes externas se sincronizan aproximadamente cada una hora. Si una
fuente falla, la aplicacion conserva los datos anteriores validos.

Por eso un favorito puede aparecer como:

- **Datos vigentes**: no cambio desde que se guardo;
- **Hay datos nuevos**: cambio algun valor;
- **Ya no esta disponible**: la fuente ya no publica ese producto.

## 10. Mensaje breve para cerrar la exposicion

> Inversion Inteligente permite comparar distintas alternativas de inversion
> segun el capital, el plazo y el riesgo. El usuario puede usar la simulacion
> sin registrarse y crear una cuenta si quiere guardar favoritos. Ademas, la
> aplicacion compara los valores originales con los datos actuales para mostrar
> si una inversion cambio.
